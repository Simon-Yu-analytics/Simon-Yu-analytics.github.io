# Junhui Yu Portfolio

A responsive, buildless English portfolio for Junhui Yu. Open index.html or serve this folder with any static web server. No installation, API key, analytics, or external font is needed.

## GitHub Pages

Upload these files to the root of the public repository Simon-Yu-analytics.github.io. In repository Settings → Pages, select Deploy from a branch, main, and /(root), then Save. Verify the returned HTTPS site address before using it in an application.

## Content

Four case studies: Store Sales Forecasting, AIWorkValue, ComplaintOps, and Unemployment and Mental Health. Repository evidence was reviewed on November 24, 2026. Store Sales scores are repository-recorded Kaggle results. AIWorkValue reanalyzes an existing experiment. ComplaintOps uses synthetic demonstration data. The ECON 483 case study summarizes the author-supplied research record and makes no numerical finding claims.

The public site excludes the private source document. Project dates and course context come from that document; repository methods and results come from the linked public materials.

## Presentation scope

This portfolio focuses on the four projects and their supporting materials. Personal social profiles and biography sections are omitted. Store Sales Forecasting remains the featured project.
